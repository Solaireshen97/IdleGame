## 部署边界

- 运行环境升级为 ASP.NET Core Runtime 10；SDK 由 `global.json` 约束到稳定 .NET 10，Microsoft 框架包为 10.0.12。
- 前后端成套发布；旧缓存客户端缺少强化/兑换请求编号时需要刷新。已提交操作的请求记录不自动过期。
- 旧库如有重名账号或重复会话令牌，迁移会明确停止并保留数据，需要先人工查明归属。
- 本地验收使用临时数据库；尚未执行真实服务器部署、自动备份调度或线上恢复，也未触发 GitHub 远端 CI。
- 发布与回滚按 [单机运维说明](single-host-operations.md) 操作，保留匹配版本的程序和数据库备份。真实容量仍需内测运行数据验证。
