# 武器技能规则与结算边界

状态：八类效果及复合技能已实现，详见 `t1-release-notes.md`。本说明以用户描述的玩法为准，不复刻 GBF 的具体公式。

后续已形成具体参数稿：[T1 武器技能与首周成长数值](t1-progression-balance.md)。等级曲线、上限及复合权重以该参数稿及发布记录为准，本文保留效果与结算边界的讨论。

## 基本规则

- 十把已装备武器均提供基础攻击和生命；只启用与主武器同元素的武器技能。
- 一把武器最多三个技能。每个技能有自己的基础等级、随机品质加成和强化等级，沿用此前三者相加的规则。
- 一个技能可以包含多个效果。复合技能占一个技能位置，提升一级会同时提升其包含的效果；其总强度需要与单效果技能比较。
- 普通 T1 武器使用两个技能，起步商店和初始赠品使用一个技能。

## 首批效果

| 效果 | 建议规则 | 结算位置 |
| --- | --- | --- |
| 攻击 | 按比例提升攻击，普通攻击与伤害技能都受益 | 攻击乘区 |
| 生命 | 按比例提高装备提供的最大生命；不自动回复当前生命 | 装备属性汇总 |
| 暴击 | 提高暴击概率，倍率初期沿用当前 150% | 单次直接伤害判定 |
| 强壮 | 生命高于 75% 时随生命比例提高伤害 | HP 状态乘区 |
| 背水 | 生命低于 50% 时随生命比例降低提高伤害 | HP 状态乘区 |
| 二连击 | 一次普通攻击行动有概率变成两次普通攻击 | 普攻次数生成 |
| 追加伤害 | 首期定义为“普攻追击”，按该次普攻结算伤害的一定比例追加伤害 | 普攻命中后 |
| 技能伤害 | 提高职业主动技能的直接伤害；不提高治疗、护盾、普攻或持续伤害 | 仅技能命中的增伤乘区 |

强壮和背水作用于普通攻击及职业技能的直接伤害。首期不直接增强中毒、灼烧等持续伤害。

## HP 曲线建议

以 `r = 当前生命 / 生效后的最大生命`、`S = 强壮最大加成`、`E = 背水最大加成`：

- 强壮加成：`S × clamp((r - 0.75) / 0.25, 0, 1)`。
- 背水加成：`E × clamp((0.50 - r) / 0.50, 0, 1)`。
- HP 状态倍率：`1 + 强壮加成 + 背水加成`。

满生命得到完整强壮收益，87.5% 生命得到一半，75% 及以下为零。50% 及以上没有背水收益，25% 得到一半，10% 得到 80%；接近零生命时接近上限，死亡角色不能行动。

每次直接攻击行动开始时由后端读取生命比例；同次行动的二连击使用同一份 HP 状态。已经结算的伤害不会因为后续治疗而改变。沿用现有回合顺序时，普攻之后使用的治疗药水不会追溯增强本轮已经完成的普攻。

具体 S、E 与各效果的等级成长曲线、上限尚待配装模拟确定，不提前沿用攻击技能的百分比。

## 连击和追击

- 二连击每次普攻行动只判定一次，最多额外生成一击；额外一击不再触发二连击。
- 两击可独立判定暴击，目标死亡则停止该次行动，不把剩余攻击转移到下一波。
- 二连击不重复使用职业技能、消耗品，不额外推进回合计数或冷却。
- 追击首期只适用于普通攻击，两次普攻各自可以附带追击。职业技能、持续伤害和追击本身不能触发追击。
- 追击依据主击已计算完暴击、属性与减伤后的伤害、但尚未被敌人剩余生命截断的数值，乘以追击比例。示例：主击计算为 100，追击 15%，追加 15。
- 追击不再次套用暴击、属性、攻击和减伤；主击击败目标时不再追加。独立向下取整，允许结果为零，避免低比例追击被保底一伤害放大。
- 固定追加伤害、技能追击、攻击触发治疗等属于以后可引入的新效果，需各自定义触发来源和叠加规则。

## 复合技能与统一叠加

示例组合：

| 技能名示意 | 组成 |
| --- | --- |
| 神威 | 攻击 + 生命 |
| 战技 | 攻击 + 技能伤害 |
| 连势 | 二连击 + 普攻追击 |
| 奋战 | 攻击 + 背水 |

名称、权重与数值已配置。复合技能不默认获得两个完整单技能的收益，否则容易全面替代单效果技能。

建议每个效果配置“等级贡献权重”。例如攻击技能每级贡献 1 个攻击有效等级，而神威每级分别贡献 0.5 个攻击和 0.5 个生命有效等级。这只是说明模型的例子，具体权重可以因效果价值不同而调整。

聚合顺序：同元素武器技能 → 按技能等级展开效果贡献 → 同效果类型相加 → 该效果的递减曲线 → 该效果上限。

例如攻击 Lv.5 与神威 Lv.4，按上述示例权重，共计攻击有效等级 7、生命有效等级 2。按这两个有效等级分别计算收益。不能先分别计算“攻击”和“神威”的递减收益再相加，否则同效果换名称可能绕开递减。

概率型效果的最终值不超过 100%；各效果允许设置独立的成长曲线及上限。不要默认所有效果共用一条百分比曲线，也不要把每个技能名称都当作一个独立乘区。

## 结算组织与后续内容

`DamageCalculator` 已具有攻击、HP状态、暴击、属性、减伤和技能伤害乘区；八类武器效果以及单技能多效果均已接入。

当前结算组织为：

1. 装备属性与效果汇总：计算最大生命、各效果有效等级、概率及数值。
2. 行动生成：普通攻击、二连击和职业技能的伤害段。
3. 单段伤害计算：统一处理威力、防御及适用乘区；技能伤害加成只作用于技能来源。
4. 命中后效果：生成受来源限制的追击，防止递归触发。
5. 日志和展示：标记普通攻击、二连击、追击、技能与暴击，说明生效的 HP 条件。

新增使用既有机制的武器、技能组合、等级曲线和掉落来源，通常只需要配置。新增吸血、护盾、反击、伤害上限等机制，仍需扩展对应的后端结算阶段、日志和测试。怪物数值、获取节奏、强化成本和职业技能强度也仍需要配套平衡。

## 本次采用的实施顺序

1. 先确认八种效果的边界、HP 曲线、复合技能叠加方式。
2. 制定各效果的等级收益、权重与上限，并分配到 24 把普通 T1 武器。
3. 改造效果配置与统一结算；覆盖 HP 边界、复合技能递减、追击非递归、目标死亡停止和冷却计数等测试。
4. 以明确的初期、成型和多人配装样本调整怪物、职业技能与补给。
