# 分阶段精英副本、深层挑战与角色精通框架

日期：2026-09-28。状态：首版框架已实现，数值与新增技能使用测试占位。

本稿整理当前讨论的通用框架，首先应用于 T1 六座十级精英副本，后续二十级等阶段副本复用。战斗数值、武器与职业技能将另行设计；当前旧数值只代表已有版本，不作为本框架的平衡依据。

## 1. 设计目标与决策边界

已经确认的规则：

- 现有十级、三波五怪的精英副本就是深层 LV1。
- LV1—LV4 同时递增怪物血量、攻击及机制完整度；LV4 是正式内容的毕业层。
- LV1 解锁 Auto；LV2—LV4 分别提供金币、击杀掉落、通关奖励方面的永久精通收益。
- 账号共享挑战资格，角色分别获得实际通关后的精通收益。
- 成熟的混合装备盘加合剂可以稳定 Auto LV4，不要求极限品质、满强化或完美魂印。
- LV5+ 沿用 LV4 完整机制，只提高血量与攻击，不再增加永久精通收益。
- LV5 起提供本阶段通用武器突破碎片，作用是替代同名突破素材。
- 未来阶段沿用这一结构，各阶段的装备、技能与具体数值可以独立设计。

本稿补充的解锁顺序、精通适用范围、奖励结算及操作流程已获本轮确认，作为首版实现规则。2026-10-01 已完成火 LV1～LV4 校准。LV2 首次降至 65% 生命后，从下一回合开始一次四回合蓄热，2.5% 实际水伤破核，成功后获得三回合 20% 增伤奖励；见 [火 LV2 参数与验证](t1-fire-deep-lv2-balance.json)。火 LV4 使用独立面板、局部回合 6/16/26 的熔岩核心循环、四回合 7% 实际水伤破核与后续三回合 20% 增伤奖励，见 [火 LV4 参数与验证](t1-fire-deep-lv4-balance.json)。火 LV3 使用同样的一次血量触发，叠加熔火扩散，破核水伤提高到5%；见 [火 LV3 参数与验证](t1-fire-deep-lv3-balance.json)。其他属性 Boss 的真实新增机制仍需后续设计。

以下记录框架首版的占位参数，仍用于未校准内容，不据此认定毕业难度或材料获取效率。火 LV2～LV4 已由上述独立配置替换，五波生命和攻击均随层数严格提高；火 LV5+ 从 LV4 面板继续沿用 ×1.1 占位增幅。

| 项目 | 本轮配置 |
| --- | --- |
| T1 开放层级 | LV1—LV10；六座副本分别配置上限 |
| 生命与攻击成长 | 相邻层 ×1.1，即 LV1 基础值 ×1.1^(层级−1)，最后向上取整；LV4 为 1.331 倍，LV5 为 1.4641 倍 |
| LV1 | 保留当前基础面板与原有技能；本轮不重新标定 LV1 难度 |
| LV2 新增技能 | 深层核心试击（占位），101% 攻击 |
| LV3 新增技能 | 深层压力试击（占位），101% 攻击，保留 LV2 新技能 |
| LV4 新增技能 | 深层循环试击（占位），101% 攻击，保留 LV2、LV3 新技能 |
| 占位技能执行 | 冷却 3 回合，按优先级轮换，用于验证分层加载及实际施放；不是正式机制循环 |
| LV5+ 技能 | 与 LV4 相同，不继续增加技能或改变技能参数 |
| 精通 2／3／4 | 常规金币 +10%／击杀道具池 10% 追加独立判定／通关道具池 10% 追加独立判定 |
| LV5—LV10 挑战奖励 | 每次成功通关有 10% 概率获得 1 个 T1 通用突破碎片；暂不逐层提高掉率 |
| 通用突破兑换 | 100 个碎片合成 1 枚同阶段通用突破石；替代一次同名素材武器消耗 |

首版通用突破石接入现有武器品质突破（`QualityRank`），不提升技能等级。当前 T1 武器适用范围由配方显式配置为物品等级 1—10，未来阶段独立配置适用范围。挑战层级的配置校验上限为 100，实际开放至 10；进一步开放需同时满足面板数值范围校验。

## 2. 四个概念分别记录

| 概念 | 含义 | 示例 |
| --- | --- | --- |
| 内容阶段 | 装备与材料所属阶段 | T1；未来的 T2 |
| 角色进入等级 | 进入内容所需的角色等级 | 当前十级；未来二十级 |
| 挑战层级 | 本次实际选择的难度 | 深层 LV1、LV4、LV7 |
| 角色精通 | 角色对这个副本已取得的永久收益档位 | 未精通、精通 1—4 |

一个副本具有稳定的身份，旗下包含多个挑战层级。例如“烛井矿窟·深层”是一座副本，LV1 与 LV4 是它的不同难度。普通八级“烛井矿窟”仍是另一项内容，不因为名字相似就共享精通。

二十级副本也从自己的深层 LV1 开始。界面分别显示“进入等级：20”和“深层 LV1”，避免把角色等级与挑战层级混为一谈。

阶段、进入等级与武器材料阶段显式配置。未来允许同阶段有不同准入等级；不通过名称或等级除法猜测材料种类。

## 3. 难度与内容结构

| 层级 | 战斗内容 | 成长意义 |
| --- | --- | --- |
| LV1：征服 | 基础技能、主题特色和完整遭遇流程 | 首次征服，进入常规刷取循环 |
| LV2：应对 | 保留基础技能，加入明确的核心机制 | 开始针对副本调整能力与配装 |
| LV3：承压 | 保留核心机制，加入未及时处理的后果 | 检验持续恢复、资源和行动安排 |
| LV4：掌握 | 基础技能、核心机制及失败压力形成周期循环 | 正式毕业，成熟配置可以稳定 Auto |
| LV5+：挑战 | 固定使用 LV4 的怪物编成与机制，只提高血量和攻击 | 检验进一步优化后的实力，获得额外材料 |

LV1—LV4 的血量与攻击逐层提高。首版六本统一使用每层 +10% 的占位成长，各副本仍分别配置，等玩家能力体系重设计完成后再标定。深层成长适用于各波所有怪物，新增占位技能只挂接 Boss。

LV5+ 不追加技能、怪物、词缀、防御成长、控制概率、层数上限、额外行动、缩短冷却或提前狂暴。攻击关联的技能伤害随攻击自然提高；技能自身的倍率与行为沿用 LV4。

T1 继续采用三波五怪，四个正式层级主要逐步补全 Boss 机制。波次数、怪物数和 Boss 数属于副本内容配置，不作为未来阶段的固定限制。

LV4 的永久精通上限固定为 4。挑战层级的开放上限另行配置；不因存在 LV5+ 就必须首版开放无限层，也不把某个更高里程碑层数写死在通用规则里。

## 4. 账号解锁、角色精通与 Auto

以下为首版采用的规则。

### 4.1 账号决定可以挑战到哪里

- 满足副本准入条件后可以挑战 LV1。
- 账号首次通关某层，开放该层的下一层，受当前开放上限约束。
- 同账号其他角色可以直接挑战账号已开放的层级，不必逐个重复低层。
- 每名参战角色都需要满足进入等级；每个参战账号都需要拥有所选层级资格，房主资格不替代其他账号资格。
- 各副本独立解锁。通关一个土属性副本，不会开放另一个风属性副本的更高层。

例如，角色 A 通关 LV3 后，账号开放 LV4；角色 B 达到进入等级后即可尝试 LV4。

### 4.2 角色决定实际享有什么收益

- 保存角色在该副本的最高通关层级。
- 精通等级等于最高通关层级与 4 的较小值；未通关为 0。
- 直接通关 LV4 的角色一次获得精通 1—4，不需要回补低层。
- LV5+ 可以刷新挑战纪录，精通仍停留在 4。
- 同队角色各用自己的精通收益，不复制队长或最高精通队员的加成。

角色 A 已精通 LV4、角色 B 尚未通关，两人一起刷 LV1 时，A 获得自己的精通加成，B 使用基础收益。B 通关后获得精通 1。

### 4.3 Auto 与挑战资格分开

- 角色首次通关这个副本任一层后，获得精通 1 并解锁这个副本的 Auto 能力。
- 解锁后可以在账号已开放的层级尝试 Auto，不额外要求每层先手动首通。
- 账号开放高层不会替其他角色自动取得 Auto；未通关角色仍需先完成一次挑战。
- 解锁 Auto 是功能资格，能否自动通关取决于角色配置。
- Auto 的角色归属、技能条件和药水规则延续现有设计；精通不提供额外战斗属性或药水次数。

### 4.4 实际参战的通关认定

沿用现有实际参战记录：角色在本轮至少参加过一次真实战斗结算，且通关时仍属于本轮队伍，才获得角色通关与精通记录。期间阵亡不取消资格；空占位置、胜利后加入、未实际参战的其他角色不获得精通。

允许满足条件的中途加入角色获得通关，不新增最低伤害占比要求。输出、治疗、保护和控制都属于有效队伍贡献。具体技术认定使用服务端参战记录，不使用客户端勾选或战报伤害排行。

## 5. 精通收益及挂机

精通作用于**同一副本所有挑战层级的常规收益**。角色完成 LV4 后，可回刷 LV1，也可继续刷 LV4 或更高层，均保留已经获得的精通。

普通八级副本、其他地区副本及未来阶段副本不共享这项加成。在线、离线、手动与 Auto 使用同一结算规则。

### 5.1 三类收益各管一件事

| 精通档位 | 结算对象 | 结算规则 |
| --- | --- | --- |
| LV2：金币精通 | 当前副本常规击杀金币与常规通关金币 | 按配置比例提高金币，不提高经验 |
| LV3：战利品精通 | 每次怪物击杀的常规道具掉落池 | 按配置概率额外独立判定一次符合条件的掉落池 |
| LV4：通关精通 | 每次胜利的常规通关道具奖励池 | 按配置概率额外独立判定一次符合条件的奖励池 |

三个收益累积保留。LV3 的追加不进入 LV4 的判定，追加结果也不会再次触发追加。

“额外独立判定”表示重新抽取掉落：基础判定没有掉武器，追加判定仍有机会掉武器；追加也可能没有产出。它不复制已掉落物品，不把每项物品的掉率直接增加若干个百分点。

常规武器、魂印、消耗品、材料和副本徽记可以进入对应追加池。首通奖励、一次性解锁奖励、挑战专属突破碎片、挑战荣誉，以及采集机会等其他系统的奖励事件不参与追加。符合追加条件的池必须在配置和预览中列明。

金币只由 LV2 提高；LV3、LV4 追加池不再次包含金币或经验。常规通关奖励和挑战额外奖励分别列出，避免重复加成。金币加成在同一轮内累计小数余量，按累计常规金币向下取整，避免每次小额掉落分别取整导致加成消失；余量不跨轮保留。

### 5.2 一轮战斗的规则保持一致

- 角色开始参与本轮时，固定该角色本轮使用的精通收益档位。
- 本轮新获得的精通从下一轮生效，不回溯重算已经击杀的怪物，也不追加本次首通收益。
- 胜利后先完成本轮应得奖励，再更新通关纪录、账号开放层级和角色精通；整体一次保存，重连不会重复发奖。
- 战败不更新通关或精通，不发通关奖励及挑战碎片；已实际取得的击杀奖励按现有失败结算规则保留。
- 同一击杀、通关及其追加抽取结果只生成一次，刷新页面和重试请求不重新抽奖。

### 5.3 挂机选择

- 玩家选择固定挑战层级重复刷取，系统不因通关而自动升层或降层。
- 精通升级后，下一轮重复战斗自动使用新收益档位。
- 战败按现有规则停止重复挑战，不自动改刷其他层。
- LV1—LV4 默认共享常规装备、魂印及徽记奖励池，不按层新增一套装备档次或额外常规掉率倍率。
- 因而精通后回刷低层是合法选择；LV4 的稳定 Auto 表示能够自动掌握完整机制，不承诺它一定拥有最高单位时间基础产出。

框架保留“更高层常规效率”独立配置的扩展位置，但本方案不默认启用。这样不会为了让玩家常驻高层而再次引入永久收益之外的强制毕业压力。

## 6. LV5+ 与通用突破材料

### 6.1 奖励边界

- LV5 起，成功通关时增加本阶段的通用突破碎片奖励判定。
- 常规副本奖励照常结算；挑战碎片使用独立奖励池，不享受精通追加。
- 更高层可以配置更高碎片概率或数量，具体效率以后标定。
- 最高通关纪录用于展示；排行榜、称号和收藏作为后续可选内容，不列为第一版框架必须完成的系统。
- 不引入周常次数、周箱、限时钥匙或赛季重置；“毕业层”的类比只用于说明 LV4 的定位。

“LV5+ 无永久收益”指不再增加永久副本产出加成。突破材料当然可以转化为武器成长，但同名武器路线始终可用，任何正式阶段内容都不以前一阶段 LV5+ 纪录为前置。

### 6.2 突破材料的职责

沿用当前提出的 **100 个 T1 通用突破碎片合成 1 枚 T1 通用突破石**，作为可配置的兑换方案；本轮不测算其获取耗时。

一枚通用突破石替代一次突破所需的一把同名素材武器。玩家先拥有目标武器，再在同名素材与通用突破石中选择一种消耗方式。

- 不能兑换尚未拥有的任意武器，也不凭空生成一把可以分解或出售的素材武器。
- 不替代技能强化碎片，不直接提供技能强化等级，不绕过武器突破上限。
- 与武器未来的突破档数、品质命名和强化上限解耦；武器重设计后，仍通过“替代一次同名素材消耗”这一接口接入。
- 默认由获得碎片的角色持有，与当前角色装备、材料归属一致；账号仓库若另行设计，再统一接入。
- T1 材料用于 T1 武器；未来阶段有自己的材料。不默认跨阶段使用、折算或升级。

现有“T1 武器碎片”仍用于技能强化，新材料使用“通用突破碎片／通用突破石”的完整名称，避免两类资源混淆。

## 7. Boss 机制框架与未来玩家技能

Boss 机制以“玩家需要具备什么能力”描述，不绑定当前某个职业或某个具体技能编号。武器和角色技能重设计时，可以据此分配能力来源。

需要表达的能力包括：指定属性输出、持续输出、爆发、承伤、单体与群体恢复、净化、驱散、打断、状态管理和防御窗口应对。能力可以来自职业、武器、魂印或补给；具体分配在后续设计中完成。

每个核心机制记录以下内容：

| 项目 | 框架要求 |
| --- | --- |
| 启用层级 | 明确从 LV2、LV3 还是 LV4 开始出现 |
| 触发与预告 | 记录触发类型、目标选择与可见预告；具体回合或阈值留空 |
| 状态进程 | 记录护甲、核心、侵蚀、寒霜等状态如何进入、积累、解除及重置 |
| 推荐应对 | 说明需要什么能力，不写必须使用哪个职业 |
| 替代应对 | 允许通过其他能力减轻后果或承受机制；不要求每种能力都能直接解除 |
| 未处理后果 | 明确与 LV3 压力的关系，避免只有模糊的“更强” |
| 循环规则 | LV4 完成一轮后如何重启；具体间隔以后配置 |
| Auto 可行性 | 至少存在一条通过配置和自动条件完成的稳定路线 |

第一版各 Boss 优先使用专用、可组合的机制处理，配合现有预告、状态与冷却系统。先不建设可编写任意逻辑的通用脚本语言。

以下沿用已讨论的主题，并统一使用仓库中的当前正式名称。旧交接稿中的深岩监工、腐巢寡妇等作为旧称参考，不据此创建另一套 Boss。

| 属性／副本／Boss | LV1 基础主题 | LV2 核心问题 | LV3 压力 | LV4 完整循环 |

| 土／烛井矿窟／沉岩督造者 | 护甲与前排承伤 | 矿脉护甲，风属性伤害参与解除 | 护甲存在期间积累地脉强化 | 护甲、强化、破除与恢复循环 |
| 暗／缄丝峡谷／缄丝巢主 | 腐蚀与持续生存压力 | 侵蚀降低最大生命 | 侵蚀积累进一步压缩生存空间 | 侵蚀施加、应对与下一轮循环 |
| 火／燧渊裂隙／烬核督战者 | 爆发与多目标压力 | 熔岩核心，水属性参与处理 | 核心期间攻击目标扩大 | 核心、爆发与恢复循环 |
| 水／镜泉冰窟／凝霜冠主 | 寒冷与输出压制 | 寒霜叠层降低攻击 | 达到阈值触发冻结 | 寒霜积累、冻结与解除循环 |
| 风／裂翎高巢／岚穹巢主 | 群体压力与状态管理 | 静电叠层 | 达到阈值释放雷暴 | 静电积累、雷暴与清理循环 |
| 光／琉辉旧庭／棱核守望者 | 护盾与防御窗口 | 反射护盾 | 反射压力提高 | 护盾开启、应对与无盾窗口循环 |

这张表定义内容结构，不宣称现有代码已经实现新增机制。LV1 基础技能也可在后续技能重设计时调整，只需保持该 Boss 的主题和分层关系。

以下行为边界需在机制实现前补成具体规则，但本轮不提前创造职业解法：侵蚀如何恢复生命上限、恢复上限是否恢复当前生命；冻结影响哪些行动；哪些状态可净化或驱散；反射覆盖哪些伤害来源，以及如何防止反射互相触发；属性破甲按命中、伤害还是其他进度计算。这些是机制语义，不等同于倍率标定。

光 Boss 尤其需要验证现有“普攻先结算”的流程：如果应对必须依赖护盾期间完全停手，当前 Auto 和战斗流程都无法直接满足。后续应选择允许自动承受、自动解除或自动调整行动的路线，再决定是否增加新的行动能力。

## 8. 玩家界面与操作流程

### 副本选择

列表展示副本名称、所属阶段与进入等级。详情默认打开“选择难度”：LV1—LV4 的选择卡片同时显示精通奖励与已获得状态，LV5+ 使用独立的挑战按钮行。首领插画与副本标题保留在顶部。

难度页展示角色精通、当前层级的收益与生命／攻击倍率，以及已有精通加成。LV4 后显示“完全精通”，更高挑战纪录不变成精通 7。账号开放上限、角色最高纪录与机制明细收进“机制与收益说明”，避免和选层重复占屏。

“敌情”和“战利品”单独切换查看，保留已选层级，并提供返回选层入口。未开放层可预览，开战按钮说明前置层级并禁用。资料加载失败时禁用开战并提供重试，避免误用上一次层级。

### 开战与挂机

角色、自动循环与开战按钮固定在底部；准备超时、公开房间与角色详细面板收进“更多设置”。默认难度页在 320×568、360×640、375×667、390×844 的触屏视口均可一屏操作，详细资料按需滚动。

房间固定一个副本和一个层级，全队面对同一套怪物。进行中不能换层，胜利后也不自动升层；创建者结束重复战斗后可重新选择层级。

### 通关结算

分别显示基础战利品、精通追加、挑战额外奖励。本次新解锁的精通单独提示“下轮生效”；首次突破最高层时显示新的账号开放层级。

仅当角色确实获得对应资格或收益时展示提示。同队其他角色的精通不显示为当前角色已取得。

## 9. 数据与配置结构

这一节说明通用职责；实际配置入口为 `appsettings.json` 的 `DungeonDepths` 与 `WeaponBreakthrough`。

| 对象 | 主要职责 |
| --- | --- |
| 副本定义 | 稳定编号、阶段、进入等级、遭遇编成、基础奖励池、精通方案、挑战方案 |
| 层级方案 | LV1—LV4 的机制组合与待标定参数；LV5+ 引用 LV4 机制及血量／攻击成长方案 |
| 账号进度 | 账号＋副本的最高通关层级；由此推导当前可挑战层级 |
| 角色进度 | 角色＋副本的最高通关层级及精通 0—4 |
| 本轮快照 | 副本、选定层级、配置版本、参战角色、本轮各角色精通和机制状态 |
| 奖励记录 | 基础／精通追加／挑战来源、角色归属、唯一事件标识及已固定的抽取结果 |
| 阶段突破方案 | 碎片编号、通用石编号、合成数量、可替代的武器阶段与突破消耗 |

普通副本保持原有配置，无需强制加入深层系统。为六个现有精英副本增加深层定义，其原有内容挂接为 LV1；不按每一层复制一套独立副本、徽记或兑换商店。

角色进度能从最高通关推导精通；如果同时保存两者，写入时必须保持一致。账号进度与角色进度不能相互替代。

已有通关、奖励与重复战斗服务继续承担各自职责，新增的层级解析、进度更新和精通奖励规则在其边界接入。跨阶段新建内容主要通过配置完成；只有新增的机制行为需要增加处理逻辑。

### 现有存档衔接

- 六座既有精英副本的编号和玩家已有徽记、装备、魂印保持对应关系。
- 使用已有角色真实通关里程碑回填该角色的 LV1／精通 1，并保留 Auto 资格。
- 只有账号通关记录时，只回填账号进度，不向账号全部角色推定精通；如果缺少角色证据，作为迁移异常单独处理。
- 不凭旧通关授予 LV2—LV4，不重新发放已经领取的首通奖励。
- 旧房间迁移为 LV1，保留已有怪物、回合和奖励记录；首次继续处理时保存深层方案快照，不重新缩放半场怪物。迁移脚本已加入，应用启动时按现有迁移流程执行。

## 10. 扩展到二十级及后续阶段

以一座未来二十级 T2 精英副本为例，只需提供新的副本编号、进入条件、怪物编成、四层机制、奖励池和 T2 材料方案，再接入同一套账号解锁、角色精通与 Auto 流程。

- 它从自己的 LV1 开始，精通仍以 LV4 封顶。
- T1 的角色精通继续保留，但不直接提高 T2 副本收益。
- T2 的 LV5+ 提供 T2 通用突破材料，不默认混发或消耗 T1 材料。
- 开放二十级内容不以刷过 T1 的 LV5+ 为前置；普通阶段准入条件单独配置。
- 复用的是分层规则，Boss 主题、解法、怪物编成和常规奖励可以完全不同。
- 不默认沿用 T1 的武器数值、角色技能、药效、怪物面板或精通百分比。

不因装备或职业技能以后调整而清除玩家已经获得的精通。若某次重大改版确实需要变更进度，另行制定明确方案。

## 11. 实施顺序与验收

本轮已完成副本身份与选层、账号解锁与角色精通、奖励来源记录、固定层级重复、层级技能组合、LV5+ 独立挑战奖励、碎片合成与通用石突破，以及对应界面和旧存档迁移。

新增技能目前只使用 101% 攻击的三种试击验证加载、施放和冷却，不代表护甲、侵蚀、冻结、静电或反射已经实现。下一阶段先重设计武器与职业技能，随后补齐六个 Boss 的机制语义、状态和循环，再标定战斗数值、精通比例、材料效率与配装基准。

数值未就绪时，开发配置可以用于验证流程，但必须标记为未平衡，不作为正式毕业难度发布。

### 框架验收：不依赖战斗平衡

- 同副本各层共享正确身份、奖励与兑换入口；不同副本和阶段的进度不串用。
- 账号逐层开放，其他角色可直接挑战已开放层；跨账号组队逐个校验资格。
- 角色直接通关 LV4 获得完整精通，通关 LV5+ 不再增加精通。
- 实际参战、未参战、阵亡、中途加入、换位和退出的通关认定符合规则。
- 同队角色精通不同，收益分别计算；回刷 LV1 仍享受已获得的精通。
- 新精通下一轮生效；断线、重连、重复请求及奖励保存重试不重复发奖。
- 击杀追加与通关追加不会互相触发，不放大首通及挑战碎片；失败只保留应得击杀奖励。
- LV5+ 与 LV4 相比只改变血量、攻击及独立挑战奖励，没有隐藏机制成长。
- 通用突破石只替代合适阶段的一次同名素材消耗，库存扣除和突破结果一起保存。
- 加入一座测试用未来阶段副本，可以复用整个流程，不复制 T1 专用业务分支。

### 后续平衡验收：等待武器和角色技能重设计

- 普通副本与地图混搭队可以首次征服 LV1，首通不依赖尚未获得的高难掉落。
- LV2—LV4 的新增机制实际产生影响，且有构筑应对空间。
- 成熟混搭与合剂可稳定 Auto LV4，不依赖固定职业或极限养成。
- LV5+ 的材料效率有吸引力，同名武器路线仍然可行，不成为正式阶段准入要求。

### 本轮验证记录

- 最终回归：服务端测试 806／806 通过；客户端编译通过，0 警告、0 错误。
- 层级与战斗：六本逐层面板、占位技能实际施放与冷却、LV5+ 沿用 LV4 技能、跨波与重复不叠乘缩放。
- 进度与奖励：账号逐层开放、其他角色跳层、跨账号加入校验、实际参战归属、每轮精通快照、独立追加、失败结算与重连不重发；测试用 T2 副本复用相同流程。
- 材料与存档：碎片兑换、品质突破、阶段限制、库存及并发校验；真实临时 SQLite 从旧版本迁移，保留进行中的战斗、库存、旧奖励和实际角色通关证据。
- 浏览器：在独立测试存档实际选择 LV1／LV4／LV5、查看锁定 LV7 与挑战奖励、合成通用石、消耗通用石提升品质、创建固定 LV5 循环房间；桌面和 390px 窄屏检查通过。修复了层级标签被显示为变量名的问题。
- 验证使用临时数据库与独立预览，未用玩家现有存档测试。以上只验证框架行为，不证明 LV4 的毕业配装与平衡已经成立。
