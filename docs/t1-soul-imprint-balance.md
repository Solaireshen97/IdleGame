# T1 Boss 魂印设计与平衡验收

本页记录六个 10 级阶段末副本的 Boss 魂印定位、Auto 释放规则与固定种子回归结果。副本生命、攻击、技能与第 22/42 回合软硬狂暴均沿用 `t1-endgame-dungeon-balance.md` 的难度基线；本轮没有通过削弱副本来提高魂印通过率。

2026-09-25 复核：本页数据已在修复按目标防护、持续伤害刷新、总减伤上限后重新生成。角色承受怪物攻击的净减伤上限为 90%，水印与骑士守护不能叠成完全免伤。扩大样本与限制见 [本轮总审计](t1-balance-audit.md)。

## 设计原则

- 六枚魂印分别解决团队增伤、个人爆发、战术打断、前排生存、技能循环、团队恢复六种需求。
- 允许纯输出魂印在平均通关速度上领先，也允许恢复魂印在药耗上领先，但同一选择不能同时成为速度、生存和队伍适配的唯一最优解。
- 重复装备可以换取更极端的收益，但团队型效果会自然出现边际递减：破甲不叠加；打断同一回合只需要一次；治疗与净化在目标恢复后不会继续空放。
- Auto 只在效果有意义时释放。玩家仍可手动安排魂印，Auto 判断不应替代玩家决策。

## 六枚魂印

| 属性 / 魂印 | 当前效果 | 初始 / 普通冷却 | 主要用途与取舍 |
| --- | --- | ---: | --- |
| 土 · 深岩监工的震核 | 150% 土伤；目标受到伤害提高 20%，持续 3 回合，同名破甲不叠加 | 3 / 8 | 一枚即可放大全队后续输出；重复装备主要只增加直伤，适合团队爆发窗口 |
| 暗 · 腐巢寡妇的毒核 | 170% 暗伤；追加本次伤害 35% 的无视防御毒蚀 | 3 / 7 | 最稳定的个人单体输出，没有防护、控制或团队辅助 |
| 火 · 熔火督军的战印 | 只在可打断预告时释放；125% 火伤并打断当前行动 | 2 / 6 | 针对危险读条和阶段技能，面对不可打断技能时会保留冷却 |
| 水 · 霜脉之王的冻心 | 115% 水伤；持有者本回合减伤 50% | 2 / 7 | 前排、脆弱角色或范围高压回合；Auto 只在持有者将受击或面对全体攻击时开启 |
| 风 · 风暴主母的雷羽 | 持有者当前所有职业技能剩余冷却缩短 2 回合 | 3 / 7 | 依赖技能循环的治疗、法术或控制职业；没有直接伤害 |
| 光 · 黎明守卫的棱晶 | 全体恢复 24% 最大生命，并各净化 1 个可移除减益 | 3 / 8 | 团队恢复与净化；Auto 会等待可净化减益或角色生命降至 75% 以下 |

土印与水印使用配置中的状态编号，不再在战斗代码中写死；光印的净化数量、Auto 生命阈值和水印的当回合持续时间也由配置定义。这样后续微调不会出现界面描述、配置值与实际效果不一致。

## 压力矩阵

`t1-soul-imprint-balance.json` 使用骑士、牧师、元素使、神射手、诡术师的精英准备配装，在六个阶段末副本中对无魂印、六种全队同印和两套混搭分别运行 5 个种子，共 270 场，结果 270/270。下表是每种配置跨六本的 30 场均值：

| 配置 | 平均回合 | 平均药耗 | 结论 |
| --- | ---: | ---: | --- |
| 无魂印 | 19.40 | 2.83 | 精英武器自身的对照基线 |
| 全队震核 | 17.23 | 2.53 | 团队增伤快，但重复破甲存在边际递减 |
| 全队毒核 | 16.17 | 1.43 | 同印压力测试中最快，代价是零控制、零防护 |
| 全队战印 | 18.80 | 1.83 | 输出较慢，但危险读条被稳定打断 |
| 全队冻心 | 18.13 | 1.43 | 针对受击回合减伤；已有强守护时收益递减 |
| 全队雷羽 | 17.37 | 2.00 | 技能循环提速，收益依赖职业技能组 |
| 全队棱晶 | 19.00 | 0.00 | 样本内不耗药，但通关速度接近无魂印基线 |
| 混搭：冻心 / 棱晶 / 雷羽 / 毒核 / 震核 | 16.83 | 1.37 | 接近纯输出速度，同时保留恢复和前排防护 |
| 混搭：冻心 / 棱晶 / 雷羽 / 毒核 / 战印 | 17.30 | 0.63 | 牺牲部分速度，换取打断和更低补给压力 |

最快配置与最低药耗配置不是同一套；两套混搭在六本中的平均回合都低于第 22 回合软狂暴线。全队同印是故意设置的极端压力测试，不是推荐配装。

## 单枚魂印与职业适配

`t1-soul-imprint-specialists.json` 每次只给一个适配岗位装备魂印：冻心给骑士、棱晶给牧师、雷羽给元素使、毒核给神射手，震核或战印给诡术师。六本各运行 3 个种子，共 126/126：

| 单枚配置 | 平均回合 | 平均药耗 |
| --- | ---: | ---: |
| 无魂印 | 19.50 | 3.11 |
| 诡术师 · 震核 | 18.61 | 3.00 |
| 神射手 · 毒核 | 18.67 | 2.72 |
| 诡术师 · 战印 | 18.78 | 2.28 |
| 骑士 · 冻心 | 19.17 | 2.61 |
| 元素使 · 雷羽 | 18.28 | 3.22 |
| 牧师 · 棱晶 | 19.33 | 1.72 |

这批适配岗位样本中，单枚雷羽最快，棱晶最省药。功能魂印应有实际取舍，无须同时比输出印更快、更省药。例如光本冻心为 19.00 回合、1.33 瓶药，毒核为 18.33 回合、2.33 瓶药；冻心用速度换取补给余量。把“所有功能印都必须支配输出印”作为门槛会反向制造强势通用选项。

该表同时改变了魂印与持有者，只能解释所列搭配。新增 `t1-audit-same-bearer-holdout.json` 把六印都放到同一神射手，保留无印对照，用 1001～1003 新种子完成 126/126，隔离职业与站位影响；共享随机流仍意味着同种子不保证不同配装遇到完全相同的随机事件。最终选择应结合队伍已有治疗、破甲、打断与承伤能力。

`t1-soul-imprint-role-coverage.json` 再以同一套“前排冻心、恢复棱晶、法系雷羽、远程毒核、灵活位震核”的混搭替换五个同位转职，覆盖全部十条转职路线。六本 × 五队 × 三种子共 90/90，六区平均 15.00～19.07 回合，没有实际承受软／硬狂暴，平均药耗 1.02。新种子替换队另为 90/90，平均 17.08 回合、1.08 瓶药。

## 自动验收

`tools/verify-t1-endgame-balance.ps1` 现在同时锁定以下边界：

- 单人、双人、三人、四人、五人以及普通/精英 Auto 的分层继续验证，机制修复后的数字允许变化；
- 九种魂印压力配置 270/270，两套混搭六本平均都早于软狂暴；
- 适配岗位单魂印 126/126；每种功能印至少在一个副本中有速度或药耗优于毒核，同时相较无印对照有实际改善，允许慢但省药的取舍；
- 十转职混合魂印替换队 90/90，并且六本平均都早于软狂暴。

先运行 `./tools/run-t1-endgame-balance.ps1` 更新人数基线，再运行 `./tools/run-t1-soul-imprint-balance.ps1` 生成三份专项报告并执行门槛。新报告记录源码指纹，`./tools/verify-t1-endgame-balance.ps1 -RequireFresh` 会拒绝使用已过期的报告。

这些结果是固定配装和固定随机种子的回归基线，不代表长期掉落概率或线上无限期胜率。玩家也可以根据队伍已有的治疗、打断和破甲能力采用其他搭配。
