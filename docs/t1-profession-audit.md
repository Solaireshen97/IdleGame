# T1 职业与转职机制审计

本页基于当前正式技能配置及 `BattleService`、`MonsterCombatService` 的实际结算。结论用于解释职业取舍，不把固定队伍的通关能力解释为十条路线完全等强。副本与魂印结果见 [综合审计](t1-balance-audit.md)；本轮十五种九点构筑的前置与实战专项见 [天赋平衡审计](talent-balance-audit.md)。

## 五个基础职业与十条转职

基础树仍承担主要循环：剑士提供招架、架势与截击；祭司提供治疗、净化和圣光循环；法师提供弹幕、驱散和伤害压制；猎人提供印记、毒素和连珠箭打断；盗贼提供连击、毒刃和凿击。当前转职各增加一项技能，进阶天赋树尚未展开，因此区别应主要体现为新增的作战窗口与队伍职责。

| 转职 | 已成立的区别 | 发挥条件 | 实际不足与边界 |
| --- | --- | --- | --- |
| 骑士 | 强化前排当回合保护，结合剑士招架与反击承担正面压力 | 对齐前排受击回合；把强守护放在弱招架之前可节省重复防护冷却 | 只保护前排存活角色，不能替全队挡范围伤害，也不能替代持续恢复或净化 |
| 战士 | 狂怒提高攻击，同时承担易伤代价，延续剑士进攻架势的吸血与连斩 | 在伤害技能可用时开启，优先利用敌方行动被打断或治疗充足的窗口 | 单项转职技能与奥术师的攻击增益有相似之处；差异主要来自剑士基础树和承伤风险，尚无独立狂怒资源循环 |
| 牧师 | 群体恢复并清除一名前排顺位队友的减益 | 队伍多人受伤或治疗与净化同时有价值时收益高；余辉可保护有效群疗中的满血队友 | 净化只有一个目标；Auto 仍须满足最低生命比例阈值，减益本身不会越过该阈值 |
| 审判官 | 用定罪制造团队易伤窗口，仍可保留祭司基础治疗 | 队伍集中输出、先定罪再接后续技能与普攻 | 个人爆发不足以独立体现团队放大价值；选择审判官会放弃牧师额外的群体恢复 |
| 元素使 | 即时高倍率攻击加灼烧，兑现直接爆发和后续伤害 | 目标能存活到灼烧结算，技能对齐伤害增益窗口 | 灼烧为固定伤害，随装备成长的相对收益需继续观察；技能伤害属性仍随主武器，没有独立的多元素切换体系 |
| 奥术师 | 攻击增益并缩短其他伤害技能冷却，强化连续施法 | 已有多个伤害技能处于冷却，且技能栏顺序配合后续施法 | 空冷却时损失主要特色收益；不缩短防护、纯治疗或魂印冷却，同一个技能也不能在同回合重复施放 |
| 神射手 | 印记与狙击形成明确的先标记、后爆发顺序 | 学会并装备标记射击，或由队友维持猎人印记 | 无印记仍可使用狙击，但得不到额外奖励；Auto 的技能顺序直接影响表现，不能用错误顺序的样本判断转职弱势 |
| 兽王 | 两段独立攻击兼顾前排当回合保护 | 需要输出与前排缓冲的队伍；防护落在敌人实际攻击前排的回合 | 同目标已有更强守护时，附带防护没有额外收益；“伙伴”目前通过两段伤害表现，尚无独立宠物状态或养成机制 |
| 刺客 | 低生命目标上的条件爆发，配合盗贼连击收尾 | 保留技能进入斩杀窗口，减少首领末段的压力 | Auto 会按冷却施放，不会主动等待斩杀阈值；手动窗口收益与长战平均伤害应分开评估 |
| 诡术师 | 烟幕削弱敌方攻击，保护效果覆盖该敌人随后攻击的所有队友 | 敌人即将发动高压攻击，尤其是范围伤害 | 削弱攻击不阻止减益施加，也不直接降低中毒等固定持续伤害；需要与净化、恢复互补 |

这些差异已能支撑承伤、恢复、团队增伤、直接爆发与控制等不同选择。成立条件也意味着没有一个职业应在每个副本、人数、装备和 Auto 设置下同时最快、最省药。替换队通关只能证明该路线在所测队伍中可用；不能证明任意阵容均衡，也不能证明两条同源转职长期等强。

## 此前已修复并保留的防护结算

- 当回合防护按目标分别保存。前排守护与后排寒霜护体、闪避可以同时生效，后排自保不会转移或占用前排保护。
- 同一目标的当回合防护取最高值，最高为 75%。Auto 跳过不强于已有保护的重复防护，允许强守护替换先前的弱招架；不会把不同角色的保护强度相加。
- 角色承受怪物攻击时，防护、天赋、状态与适用操作药在既有减伤乘区内合并，净减伤封顶 90%。骑士守护叠加水魂印因此不能达到完全免伤。易伤仍参与同一乘区计算，攻击削弱和属性倍率保留原有独立结算；持续伤害沿用自己的规则。
- 招架明确以自身为目标，Auto 根据施法者自身生命判断。奥术弹幕描述已校正为提高目标受到的伤害，与实际状态效果一致。

这些防护修复来自此前副本、职业与魂印复核，本轮继续保留。稳守的反击与以守为攻的追击要求自己的招架或守护实际保护自己并受击；常驻减伤、魂印或队友提供的保护不能单独触发，相关文案已明确这一边界。

## 本轮天赋机制优化

- **连绵攻势**保留毒箭额外一层中毒，并延长为五个后续回合；该次毒箭施加后达到三层时，再触发一次有效基础攻击 30% 的无视防御毒蚀。毒蚀不暴击、不叠加额外伤害乘区、不消耗层数，每次毒箭最多一次。单人首次施放只有两层，需要后续施放或队友毒刃配合进入满层收益；普通中毒的每层伤害与三层上限未变。
- **霜心与金蝉脱壳**让对应自保技能在自身有可净化减益时也能触发 Auto，保留原生命阈值条件。只有队友有减益、状态不可净化或未购买终极时，不增加此触发条件；更强的现有守护不阻止这次自净化。
- **余辉庇护**允许已经成立的群体治疗为满血队友提供过量保护。全队满血且无可净化减益时，不会仅为制造余辉而自动消耗技能冷却。
- **圣光回响**只在真实恢复生命时消耗治疗增益并生成伤害增益；群疗纯净化、仅产生满血余辉保护均不冒充治疗循环。

群体治疗的 Auto 仍同时受到两层检查：最低生命比例低于或等于所设阈值，且存在实际受伤者或可净化目标。可净化减益只满足第二层，不会自动绕过生命阈值；将阈值设为 100% 时可对满血但带减益的队伍施放纯净化，仍不对全满血且无减益的队伍空放。霜心、金蝉的新增条件不改变群疗规则。以上技能 Auto 还要求对应角色处于自动战斗状态且技能 Auto 已启用。

本轮还减少祭司净化、灼目圣光的不必要绕路，并为法师、猎人、盗贼第三层增加同分支根节点入口，保留原有中枢混合路线。细节和合法构筑枚举见 [正式设计](formal-talent-and-promotion-design.md) 与 [前置审计数据](talent-prerequisite-audit.json)。没有为使旧数字不变而修改首领面板或魂印冷却；连绵等天赋的实际收益已改变，应按当前回归判断。

## 仍需统一的状态时长口径

当前通用状态的 `DurationRounds = N` 表示施加后继续保留 **N 个后续回合**，在最后一个后续回合结束时移除。例如施加回合记为 R，即时增益或减益可在 R 当回合生效，并保留到 R + N 回合结束。于是“持续两个回合”的即时攻击增减益可能影响施加回合和两个后续回合；技能短文案尚未清楚表达这一口径。

中毒、灼烧首次施加后从下一回合起跳伤害。此前已修复刷新导致旧跳伤暂停的问题；本轮进一步规定有效持续伤害的到期时间取旧应用与新应用的较晚值，普通毒不会截短连绵的延长毒。过期或净化后的新感染重新按新时长、一层起点计算。沉默针对下一回合意图。普通 Guard 是当回合防护，不使用上述通用状态寿命；水魂印屏障也有明确的当回合处理。

本轮保留现有寿命语义，不把所有状态统一缩短一回合。风餐露宿的荒野韧性、慈悲祷言、余辉庇护现已准确标注为“本回合及下回合”。其他即时增减益仍需后续统一玩家可见的描述与剩余回合显示；不能用持续伤害的首次跳伤时间直接解释即时增益。

## 后续评估重点

- 区分队伍整体收益与个人输出，比较同源转职在不同副本中的回合、药耗和失败原因。
- 把 Auto 与手动窗口分开：优先验证神射手印记顺序、刺客斩杀保留、奥术师冷却收益和防护施放顺序。
- 长期成长时重新检查固定持续伤害、多段攻击逐段受防御影响，以及兽王、战士等当前主要依赖基础树维持特色的路线。
