# 职业天赋平衡与前置复核（2026-09-25）

版本说明：下述实战样本和源码指纹对应职业天赋复核完成时的快照。随后统一了账号内角色的 Auto 开关、魂印自动释放门槛，并增加取消准备；本次功能修改未重跑这些数值样本，因此下文的“当前”及验证结果均指该天赋快照，不能视为修改后的最新数值验收。现行操作规则见 [README](../README.md)。

本轮把前置的实际取得等级、终极机制的有效收益和同职业构筑的实战表现分开验证。结论是：此前确有不必要的绕路和失效收益，现已修正；15 套参考构筑都能完成所测内容，但这不代表所有合法加点等强。没有修改天赋节点代码、被动属性数值、最大等级、投入门槛或互斥规则，旧存档不需要重算被动面板。

有效持续伤害被刷新时只延长、不被队友的短毒缩短；过期或净化后重新感染采用新时长和一层起点。五回合强化毒能够连接毒箭的五回合冷却，因此猎人持续路线有积累过程，也能与盗贼毒刃配合。全局状态仍沿用“施加当回合＋后续 N 回合”，慈悲、余辉、风餐露宿的文案已明确为本回合及下回合；剑士反击描述明确要求自己的招架／守护实际保护自己并受击。

## 特色、取舍与证据边界

这些是可达性与内容适配的参考构筑，不是穷举最优解。战术路线往往带更多主动伤害、驱散或打断；当前没有共享行动点，因此主动技能广度对 Auto 效率的收益很明显。法师、猎人、盗贼的战术参考构筑在本次样本中较快，不能据此宣称三种路线已完全等强。法师战术栏放弃寒霜护体，猎人战术栏放弃野外包扎；这是真实的技能栏成本，但药品充足、固定站位和治疗队友降低了这些成本在本轮样本中的可见程度。

纯生存投入应理解为自身容错、恢复利用和净化能力，不保证每场比提前击杀敌人的路线更省药。尤其后排职业的生命与自净化不会直接保护前排：本轮盗贼生存参考队仍有队友减员。骑士进攻的吸血、牧师进攻的圣光回流兼有恢复，不能把“进攻”标签理解为完全放弃生存。

法师、猎人、盗贼战术参考队相较进攻参考队的终局平均用时优势分别约为 3.6%、5.0%、5.3%，小于单人刷图的差距。猎人生存在两种单人内容合计平均耗药 2.17 瓶，战术为 2.25 瓶，显示速度以外的收益；当前参考集没有证明所有职业的生存方向都有相同程度的优势。

模拟统一使用 75% 技能生命阈值；普通防护仍主要按生命触发，不会自动为所有危险预告选择最佳时机。较早的治疗也可能避开慈悲的低于半血条件，单人治疗不一定产生余辉所需的过量治疗。因此这些数据反映当前 Auto 下的表现，不能代替手动或专门设置阈值后的上限评估。下一轮若继续调优，应先比较防护预告与治疗阈值策略，再决定是否需要改被动数值。

本轮没有因为单一刷图矩阵就上调所有生存属性或削弱所有混合构筑；保留职业和遭遇差异，优先修复确定的前置绕路与机制失效。未来若调整被动数值或收紧已经开放的前置，须同时处理旧角色缓存的天赋属性或洗点迁移，不能只修改配置。

模拟不包含从零养成、首通 Auto 解锁、长期补给经济、真人手动时机或所有合法构筑。千瓶初始药用于测战斗，不是玩家预期库存；同种子也不保证不同技能栏消耗相同的随机序列。更高等级、无补给持久战和多人同职业叠加需要独立校准。
