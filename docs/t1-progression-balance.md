# T1 武器技能与首周成长数值 V0.1

状态：本文保留首版数值依据与历史首周测算。当前武器技能、六把 Lv1 首怪主武器和战斗公式以[当前武器技能三档设计](weapon-tier-balance.md)为准；下文旧时间与养成路线尚未按新数值重新模拟。

## 0. 目标与结论

本稿记录已落地的数值设计及原始离线测算。目标由用户确认：每天约12小时有效挂机，约一周（84小时）获得一套尚未毕业、能体验本阶段大部分内容的装备；之后通过毕业装备提高刷取效率。

三种装备标准：

| 标准 | 配装要求 | 目标体验 |
| --- | --- | --- |
| 可玩装备（首周） | 十槽，主要技能与主手同元素；绿装为主、夹杂蓝装；关键技能 +2，其余约 +1；有 2～4 把副本/精英特色武器 | 大部分普通地区与正式副本可玩，能挑战精英怪和初版 Lv.10 精英副本 |
| 阶段毕业（后续数周） | 目标技能组合齐全；蓝装为主、有少量紫装；关键技能强化至 +4～+5，其他按收益补齐 | 提高输出、生存与挂机稳定性；具体收益待新版品质模型实测 |
| 收藏极限 | 全紫、目标技能全部 Lv10（从 Lv1 强化九次） | 长期追求；不作为任何首通或正常挂机的必要条件 |

“约一周”是待真实战斗验证的节奏目标，不是已经证明的通关时间。熟练路线、掉落运气、有效运行时长与多人帮助都会改变实际进度。首次挑战不等于稳定全自动通关。

以单角色建立基准。2026-09-27 起，普通讨伐与精英讨伐按角色人数采用 `100 / 180 / 260 / 340 / 420%` HP，副本保持固定强度；规则通过战斗内容的显式方案配置。中途加入保留剩余血量比例，每场重开按最新阵容计算，奖励不增加人数扣减。此前的离线测算没有包含这套规则，不能把单角色的 84 小时目标直接套用到五人队伍；多人和自建五角色队伍的获取节奏仍需按新规则与完整循环时间重新验证。详见 [README 人数与生命规则](../README.md#讨伐人数与怪物生命)。

## 1. 获取与成长阶梯

武器基础数值使用 `攻击 + 生命 / 2.5` 作为粗略分配预算；它仅用于分配，不代表两种属性已被证明等价。

| 来源 | 基础数值预算 | 初始技能 | 品质 | 作用 |
| --- | ---: | --- | --- | --- |
| 初始十槽 | 每把攻击90 / 生命110 | 生命小 Lv.1 | 固定普通 | 同属性商店模板各一把，创建角色时直接装备十槽 |
| 商店 | 攻击90 / 生命110 | 生命小 Lv.1 | 固定普通 | 购买额外实例用于替换；六元素价格一致 |
| 普通讨伐 | 六把首怪主武器采用新面板，其余沿用旧面板 | 首怪主武器攻击中 Lv1；满突破解锁第二技能 | 固定普通 | 建立主属性和配装方向 |
| 副本兑换 | 42：例如20 / 55、22 / 50、18 / 60 | 两技能，各 Lv1 | 固定普通 | 对指定武器提供稳定获取渠道 |
| 正式副本 Boss | 44～46 | 两技能，各 Lv1 | 固定普通 | 获取有特色的组合与更高生存/输出 |
| Lv.9～10 精英怪 | 46 | 两技能，各 Lv1 | 固定普通 | 提供后期侧重型武器，准备精英副本 |
| Lv.10 烛井矿窟·深层LV1 | 48～50 | 两技能，各 Lv1 | 固定普通 | 本阶段最后一档装备，保留长期优化空间 |

首批 T1 包括后续精英装备，都先使用两个技能位置。数据结构仍允许最多三个；第三个位置会额外增加强化收益，不能当作免费装饰添加。相同武器允许重复装备。

高阶武器不必在所有配装中替代低阶武器。同技能方向、同品质强化水平下应有明确进步；换错技能组合可能降低输出，这需要装备比较界面说明。

全部仍属 T1、使用 T1 材料。挑战等级只作推荐提示，不限制角色进入。

## 2. 起步商店与经济

- 注册只创建账号，首次进入游戏复用角色创建表单，由玩家填写名称、选择职业；未创建首个角色时会进入创建页面。首个角色自动设为当前角色并获得 120 金币，后续创建的角色从 0 金币起步。每个角色直接获赠并装备十把同属性商店武器：剑士火、祭司光、法师水、猎人风、盗贼暗；同款可在商店以 40 金币购买额外实例。
- 六种元素的商店武器统一 40 金币，攻击90、生命110、生命小 Lv.1；固定普通品质，不在商店随机品质。十槽起始基础总计900攻击、1100生命，生命小技能合计 Lv.10，获得20%武器生命加成，有效最大生命1320。商店购买的同款武器先进入背包，可替换已装备实例。此组基础数值为当前配置，旧版18/45的离线预算与实战推断不再适用。
- 初始赠品换下并解锁后可按武器售价出售，不产基础分解材料；起步金币只发给首个角色。
- 商店装备可以出售，售价8金币。未强化时不能分解；强化后不产基础碎片，仅返还已投入强化材料的50%（向下取整）。普通掉落武器产1枚基础碎片，副本/精英武器产2枚。
- 后端需保存装备来源，按来源决定回收基础收益；不能只依赖当前武器模板或锁定状态，防止旧掉落实例被错误当作商店物品。模板基础字段保留正数，实际回收数量由后端结合装备来源计算，允许商店来源为0。
- 新手首次完成讨伐额外给一把固定普通品质的目标武器，只发一次，帮助玩家看到“购买 → 战斗 → 掉落替换”。这项新手保底需要明确的后端领取记录。
- 普通讨伐初步沿用每次7～12金币的量级。常规挂机目标应让药水掉落覆盖大部分消耗；如果每场普通讨伐都必须大量购药，应调整难度或治疗效果，否则商店填槽会被消耗品支出拖慢。

金币购买消耗品，碎片升级武器技能，通用材料定向拿装备；同款武器或通用突破石用于主动升阶。资源均不允许负数支出或前端指定奖励。

## 3. 当前技能档位与战斗结算

当前规则共有十二类效果，每类小/中/大三档。各技能按自己的每级系数计算，再按效果类型合并封顶；复合技能每级贡献两项“小”效果。完整数值、条件与公式见[当前武器技能三档设计](weapon-tier-balance.md)。原先按统一每级系数和有效等级权重的测算已失效。

暴击伤害仍为150%；二连击最多多攻击一次；普攻追击复制已结算普攻伤害。强壮在生命75%时降为零，背水与坚守低于50%后线性增长；坚韧与坚守的武器减伤合计最高50%，再与守护/状态乘算，直接承伤综合减伤最高90%。精进按本次挑战回合数增长，第10回合封顶；克敌只扩大实际克制的属性优势。

十把两技能武器全+1需40枚，全+2累计120枚，全+3累计280枚。首周目标是重要技能+2，其余约+1，不要求全+2或全+3。

每条技能九次强化依次消耗2、4、8、8、8、8、8、8、8枚，累计62枚。已记录的实际投入不随调价重估；仅缺少投入记录的旧技能按历史价格回退估算。分解继续返还实际投入的50%，整除向下取整。基础碎片来源另按装备来源与档次决定。

### 掉率与效率（已配置）

- 普通讨伐 Lv.1～2 为 3% + 1%，Lv.3～4 为 6% + 2%，Lv.5～7 为 10% + 4% + 2%，各条目独立判定，概率之和表示期望产出数量；首次普通讨伐提供账号一次性的普通品质主掉落武器。
- 区域副本 Boss 专属武器掉率为 5%，精英专属武器为 3%，各有同属性普通武器 2% 的独立副掉落。终局 Boss 击杀为区域原兑换武器 2% + 普通武器 1%；高级武器在通关时独立掉落，概率为 6%、4%、3%、2%、2%、1%。普通副本兑换 12 徽记、终局 18；每次通关 1 枚、账号首通额外 2 枚。完整配置见 [区域掉落明细](region-loot-design.md)。
- 所有新获得武器固定普通品质（突破阶级0）。现有模板中每条已配置技能均从 Lv1 开始；突破阶级 0/1/2/3 对应总等级上限 Lv4/Lv6/Lv8/Lv10，分别可强化 3/5/7/9 次。消耗一把未装备、未锁定的同模板武器或通用突破石可主动升一档，素材品质不限，素材的强化投入不继承。
- 原设计曾以普通每把12.5分钟、正式副本18～24分钟作为目标。真实循环因职业、属性与配装有明显差异，不能继续把这些目标用于计算实际进度。
- 实测首周配装正式副本循环约11.5～19.6分钟；每个场景仅5个种子。第一把兑换需要10次通关，按该循环参考约1.9～3.3小时，不包含首次手动输入。
- 八项效果、实战循环和材料投影已接入独立服务端模拟，详见发布记录。资源投影不等于从注册到84小时的全流程验证。

## 8. 首周路线目标（累计有效挂机）

| 时段 | 主要活动 | 希望获得的进步 |
| --- | --- | --- |
| 0～2小时 | 购买起步装备、完成新手首通、低级讨伐 | 从3槽逐渐补到6～10槽，第一次用掉落替换商店装备 |
| 2～12小时 | 选择主属性，刷几种目标普通怪 | 获得核心武器与一批绿色品质，开始少量+1 |
| 12～24小时 | 完善普通配装、补生命与技能组合 | 十槽基本齐全，关键普通技能+1，能尝试首个正式副本 |
| 24～48小时 | 探索正式副本、积累徽记 | 获得若干Boss/兑换武器，能体验不同区域的机制 |
| 48～72小时 | 正式副本与Lv.9～10精英交替 | 核心技能逐步+2，输出和生存满足精英挑战 |
| 72～84小时 | 补缺口、尝试Lv.10精英副本 | 形成可玩装备；通关依赖正确配装和应对，不要求紫装 |
| 首周以后 | 更高品质、关键+3、补齐目标组合 | 减少回合数、提高稳定性、挑战更难目标 |

这是目标路线，不设置日历强制解锁。1～10级累计经验已从早期占位值540提高到6250，单级需求为60/120/220/350/500/700/1000/1400/1900。角色高于挑战经验参考等级 5/6/7/8 级时，经验依次降为75%/40%/15%/0%，金币、装备与材料不衰减。第一版目标为约7～10小时到达8级、18～24小时到达10级；这是根据试玩速度制定的校准目标，仍需新角色实测验证。等级仅作难度提示，装备和战斗应对决定能否击败目标。

原始校准目标优先以回合数与胜率为标准（现有实测见发布记录）：可玩装备普通目标约4回合、毕业约3回合；同一副本首领可玩约12～15回合、毕业约9～11回合。当前自动战斗为20秒回合间隔，怪物在击杀后5秒刷新，刷新时间包含在回合冷却内；4→3回合约减少25%循环时间、提高33%单位时间次数。实际副本还包含手动准备、波次和结算，应使用完整循环计时。

## 9. 已完成的离线测算及局限

运行 `node docs/t1-balance-model.mjs`，输出 `t1-balance-results.json`。脚本仅写设计结果，不访问数据库。

模型条件：十武器与主手同元素；敌方防御为0、属性倍率100%；生命比例固定；暴击取期望；普攻每回合一次，职业技能折算为每回合0.5次100%攻击的直接伤害。未模拟药水、生命波动、职业真实冷却、状态、死亡截断、多段取整或多人队伍。

- 对六元素的四把普通武器，枚举十槽所有286种重复装备组合，在0/+1/+3强化和四种生命比例下分别比较，并另加600最大生命约束。
- 加入六类兑换武器及对应Boss武器后，每元素枚举184756种组合，在90%和25%生命、每技能+1且至少600最大生命时比较，共2217072组。
- 普通武器每技能+1、90%生命时，最佳混搭比十把最高基础攻击武器高约1.8%～15.9%期望直接输出。需要至少600生命时，最优配装进一步加入防护武器。
- 同条件下，兑换/Boss的600生命配装模型输出在约636～661之间，六元素差距约4%。25%生命时，火、土、暗的背水组合收益提高，但模型未计入维持低生命的风险。
- 旧模型中“品质点直接提高技能等级”的示例已不适用于当前版本。现在品质本身不立即提高战力；还需投入对应碎片强化到新开放的等级。品质对首周进度与长期刷取效率的影响需要重新测算。

此模型帮助发现明显的单一配装优势并确定第一版参数，不能证明一周进度已经平衡。现已补充使用真实服务端的战斗模拟，覆盖普通职业、不同属性、单角色/多人及实际循环时间，见 `t1-release-notes.md`。失败后仍按正式规则停止，不模拟自动无限重试。
