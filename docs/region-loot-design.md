# 六属性区域装备掉落

状态：2026-10-01 已接入首批深层武器的击杀掉落、固定通关碎片和六十徽记兑换；完整武器数值见 [六属性武器清单](current-weapon-catalog.md)。

## 掉落规则

- 六个区域的普通怪、精英、区域副本和终局副本怪物，武器击杀掉落全部对应区域属性。
- 六只 Lv.1 首怪各配置一把主武器；其他普通讨伐和精英保留主、副掉落。入门副本和深层副本使用独立的装备池；深层前四怪可共享同一两武器池。
- 普通讨伐六只 Lv.1 首怪为主武器 5%；六区 Lv.3 为过渡主武器 5% + 首怪武器 2%，Lv.5 为新主武器 5% + Lv.3 武器 2% + 首怪武器 1%。其余 Lv.2 为 3% + 1%，Lv.4 为 6% + 2%，Lv.6～7 为 10% + 4% + 2%；武器组合按怪物身份分配。
- 区域副本普通小怪为 4% + 1%，较强小怪为 6% + 2%，保持原来的期望武器数量。
- 精英专属武器掉率为 3%，另有一把同属性普通武器 2%；区域副本 Boss 专属武器掉率为 5%，另有一把同属性普通武器 2%。专属武器仍只有原本的专属来源。
- 六本深层前四只怪均对所属两把首批深层武器各作 1% 独立判定，Boss 各作 5% 独立判定，均为普通品质、零突破、两条初始技能 Lv1。
- 六本深层普通通关固定获得 5 枚 T1 武器碎片、1 枚本副本徽记，魂印另有 1% 独立掉率。通关不再追加武器；旧三十六武器获取池与十八徽记占位价格已替换为本区域两把新武器及每把六十徽记兑换。
- 每个掉落条目独立判定；有副掉落的怪物可以同时掉落主、副武器，也可以都没有。概率之和代表期望产出数量，不是至少获得一件武器的概率。
- 每个角色首次通关每个地区的 Lv.1 首怪讨伐各获主武器一把，固定普通品质、0 突破、已解锁技能 Lv1。
- 六只 Lv.1 首怪每次胜利合计 12 职业经验、10 金币；通关保留 35% 小药水，并有 30% ×1 T1 武器碎片。六区 Lv.3／Lv.5 讨伐通关分别有 50%／70% ×1 T1 武器碎片。普通挑战的金币、经验、消耗品与碎片沿用既有配置；深层奖励和兑换按上文。
