# 六属性区域装备掉落

状态：2026-09-27 已落地。当前配置为准；完整武器数值见 [六属性武器清单](current-weapon-catalog.md)。

## 掉落规则

- 六个区域的普通怪、精英、区域副本和终局副本怪物，武器击杀掉落全部对应区域属性。
- 每只怪配置 2～3 把武器，有明确的主掉落和低概率副掉落；不同怪物不会使用完全相同的武器与概率组合。同名怪重复出现时可以沿用相同掉落。
- 普通讨伐 Lv.1～2 为 3% + 1%，Lv.3～4 为 6% + 2%，Lv.5～7 为 10% + 4% + 2%。每只怪的武器概率之和保持原来的 4／8／16，维持期望武器数量；武器组合按怪物身份分配。
- 区域副本普通小怪为 4% + 1%，较强小怪为 6% + 2%，保持原来的期望武器数量。
- 精英保留专属武器 20%，增加一把同属性普通武器 2%；区域 Boss 保留专属武器 18%，增加一把同属性普通武器 2%。专属武器仍只有原本的专属来源。
- 终局前两只小怪为同属性普通武器 3% + 1%，两只守卫为 6% + 2%；终局 Boss 为本区域原兑换武器 2% + 普通武器 1%。这些是新增的低阶装备来源。
- 六座终局副本各自通关掉落六把本区域属性的现有高级武器，主掉落 6%，其他为 4%、3%、2%、2%、1%；原本主题武器是主掉落。每本的高级武器期望数量仍为每次通关 0.18 把，全部 36 把仍可通关刷取。
- 每个掉落条目独立判定，可以同时获得主、副掉落，也可以都没有。概率之和代表期望产出数量，不是至少获得一件武器的概率。
- 首次普通讨伐的新手奖励取该怪的主掉落，仍为账号一次、普通品质。已有房间启动时同步新的掉落入口，不重置战斗进度；已记录待结算的奖励与品质快照保持原样。
- 装备编号、图像、名称、数值、技能、品质规则、强化和已有装备不变；金币、经验、消耗品、代币、魂印与首通奖励不变。兑换列表和价格保留现状，仍是六属性兑换。
