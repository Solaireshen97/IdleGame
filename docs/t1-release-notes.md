## 已实现的养成规则

- 十把武器提供基础攻击与生命，主手决定元素，只有同元素的技能贡献生效。
- 八类效果：攻击、生命、暴击、强壮、背水、二连击、普攻追击、技能直接伤害。
- 神威、战技、奋战、连势可同时贡献多个效果；同效果先合计有效等级，再应用同一条递减曲线与上限，不能用不同技能名称绕过递减。
- 强壮在生命高于75%时生效，背水在低于50%时生效；界面显示的是最高增伤，后端按当前生命计算。
- 二连击最多两次普攻，追击只跟随普攻；击杀目标后停止后续攻击，不跨怪物追击、不额外扣药、不推进额外冷却。
- 品质额外技能点0/1/2/3与强化独立，概率60%/25%/12%/3%；每项技能强化上限+3，逐级费用2/8/24。
- 分解返还基础碎片与实际强化投入的50%，向下取整。普通掉落基础1片，其余正式武器基础2片。
- 商店装备不产基础碎片，出售8金币；没有强化投入时后端拒绝分解。强化后可以分解，但只返还实际投入的50%。初始赠品不可出售、无基础分解碎片，同样只有存在强化返还时才能分解。
- 新账号获得120金币。账号第一次普通讨伐胜利额外获得固定普通品质目标武器，跨角色只发一次，写入统一奖励账本。

详细技能表、曲线与权重见 [数值设计](t1-progression-balance.md)，具体普通与精英名单见 [普通武器](t1-field-weapons-design.md)、[精英及深层武器](t1-elite-weapons.md)。

## 实际战斗模拟

`tools/Game.BalanceSimulator` 使用真实 BattleService、MonsterCombatService、RewardService，以及内存SQLite和固定随机种子。没有连接用户数据库，也不等待真实30秒，而是累计真实服务端截止时间后推进时钟。

共870场：六属性×两职业的起步/商店120场、普通成型/首周/后期720场，另有30场五人队伍。每个配置5个种子，结果是这些样本的观察值，不是已证明的长期胜率。

配装预设：

- 起步：一把16/40初始武器加两把商店武器；商店阶段为十把商店武器。
- 普通成型：四种普通武器按4/3/2/1装入，白色、两技能各+1。
- 首周参考：八把普通武器加一把对应Boss、一把同元素矿洞兑换，绿色点放第一技能，第一技能+2、第二技能+1。
- 后期参考：五普通、二Boss、一矿洞兑换、一精英、一深层兑换，蓝色点分配1+1，第一技能+3、第二技能+2。它不是全紫或理论最优毕业盘。
- 成型以后的角色都为10级、合法9点天赋，药水充足、自动阈值70%，已通关解锁Auto，满生命进场。这些是预先供应的配装，模拟不包含刷取它们的时间。

### 单人循环时间

成功循环包含30秒重开和波次等待。区间是六元素各场景均值的最小与最大，不是单场随机上下限。

| 职业 / 目标 | 普通成型 | 首周参考 | 后期参考 |
| --- | --- | --- | --- |
| 骑士 / Lv.7讨伐 | 1.3～2.8分 | 1.1～2.6分 | 0.6～1.9分 |
| 牧师 / Lv.7讨伐 | 2.9～3.7分 | 2.4～3.5分 | 1.9～3.3分 |
| 骑士 / 正式副本 | 12.4～15.9分 | 11.5～15.1分 | 8.1～11.4分 |
| 牧师 / 正式副本 | 16.2～21.2分 | 14.8～19.6分 | 10.9～15.0分 |
| 骑士 / Lv.10精英 | 5.6～7.6分 | 5.0～6.8分 | 3.5～6.0分 |
| 牧师 / Lv.10精英 | 7.9～10.0分 | 7.1～9.8分 | 5.4～8.9分 |

这些普通/正式/精英场景均为5/5成功。正式副本同元素同职业的后期单位时间通关次数比首周提高约17%～42%；这是配装、机制与回合取整共同作用的结果，不能直接称为常驻攻击提高相同比例。

### 深层与组队

深层首领为土属性：风属性显著有利、水属性不利。首周样本中风骑士/牧师均5/5成功；水骑士/牧师均0/5。后期水骑士1/5、牧师0/5，其余五元素两职业均5/5。水属性需要调整技能、防护与主手，或组队；不能把“后期装备”解释为所有元素在任何敌人上都能挂机。

五人队伍使用三骑士两牧师、同档首周装备，火/水/风各测正式与深层：30/30成功，正式循环1.1～1.2分、深层2.3～3.6分。目前没有人数缩放，组队速度远高于单人，84小时目标不适用于五人队。

测试中普通讨伐药水消耗为0。正式副本消耗随配装下降；早期土牧师打10级精英有每次约2金币的净购药缺口，可以由普通讨伐收入补足。模拟供应充足药水，因此不宣称零补给可以长期运行。

## 首周资源测算与限制

`tools/t1-economy-projection.mjs` 将十条转职路线的首周参考配装实测循环与正式掉率连接，每个转职/元素组合进行2000次随机抽样，共60组。参考分配为普通讨伐40小时、一个正式副本30小时、精英12小时、探索及首次终局尝试预留2小时。

- 保留八把目标绿色以上普通武器、一把Boss、一把兑换、一把精英，分解其余武器；不计强化返还与失败掉落。
- 可用碎片中位数约202～757；当前十项主技能+2、十项副技能+1共需120片，全+3需680片。
- 对应兑换约8～15把，蓝色以上Boss武器中位数2～5把，仍不保证指定极品品质分配。
- 在该固定路线和首周参考配装的战力假设下，60组各2000次均达到资源条件。**这不是从注册到84小时的全程挂机模拟，也不是实际完成概率100%。**

尤其不能据此证明玩家必须花满一周：该模型不逐步更新战力、没有模拟换装材料损耗、早期手动首通与低等级目标的实际循环，并假设四种目标普通武器有相同代表循环。熟练路线、光/风爆发、组队会提前成型。当前版本以“首周能玩到主要内容，之后刷品质与强化提高效率”为目标；更精确的天数需要试玩或真实进度遥测再校准，不引入强制日历等待。

原始结果：[实战](t1-combat-final.json)、[起步](t1-combat-entry.json)、[组队](t1-combat-party.json)、[资源投影](t1-economy-projection.json)。

- 服务端、客户端与校准器构建通过，317项测试通过；最终构建0警告、0错误。
- 自动测试覆盖八效果、曲线边界、真实伤害/回复与药水预览、双击/追击死亡截断、冷却、奖励幂等、来源回收、模板/快照升级及旧库迁移。
