# 六个初始地区（Lv.1～10）

地区用于组织大厅挑战与固定属性的特色掉落。玩家可以自由切换地区；没有阵营、出身或旅行消耗限制。各地区均覆盖 1～10 级，同等级路线可交替体验。

大厅地区按火、水、土、风、光、暗排列。每区可见的普通讨伐、组队试炼与深层副本均使用地区属性。旧讨伐与精英定义暂留在内部，但不再提供大厅入口。

## 地区与正式副本

| 地区 | 普通组队副本 | 首领 |
| --- | --- | --- |
| 赤烬荒原 | 燧渊裂隙 | 燧渊领主 |
| 雾凇雪境 | 镜泉冰窟 | 凝牙狼王 |
| 岩芽林地 | 烛井矿窟 | 砾牙矿主 |
| 长风原野 | 裂翎高巢 | 裂翎巢母 |
| 琉辉之森 | 琉辉旧庭 | 失序辉庭卫 |
| 墨雾幽林 | 缄丝峡谷 | 缄丝蛛后 |

地区、阵营与怪物显示名称采用本项目独立命名。水属性覆盖冰霜主题。

地区与挑战保留稳定的内部代码，显示名称和插画沿用现有资源。普通本的奖励与兑换已按新结构调整。

每区有 5 个可见挑战，共 30 个：

- 推荐 Lv.1、3、5：三个单体讨伐。
- 原 Lv.8 普通副本：首次组队试炼，提供经验、金币、补给和通用武器碎片；4 波、7 名敌人。
- 深层副本：账号先通关同地区普通副本，才可挑战深层 LV1；之后逐层解锁。跨账号队员各自需要达到账号前置。Auto 与精通仍按角色分别记录。
- 所有战斗均可由低于推荐等级的角色创建、加入、上阵和预约。等级只作难度参考；职业、技能和十级转职规则仍然保留。
- 经验衰减使用挑战的经验参考等级：高出 0～4 级为 100%，高出 5/6/7 级为 75%/40%/15%，高出 8 级及以上为 0%；满级不再获得经验。

## 首领的战斗区别

- 砾牙矿主：破甲、前排重击与低生命强化。
- 缄丝蛛后：前排毒伤、全体毒雾、低生命蛛茧防护。
- 燧渊领主：全体灼烧、破甲劈砍、低生命攻击强化。
- 凝牙狼王：前排破甲、全体霜寒降低攻击、低生命冰甲。
- 裂翎巢母：前排俯冲、全体风暴、低生命战歌强化。
- 琉辉守卫：前排奥术衰弱、全体辉光冲击、低生命护盾。

新首领各有三种技能，沿用服务端持久化的回合意图、技能冷却和战斗前预告。全体危险技能不可打断，可通过防护、净化等方式应对；护盾和强化可驱散。新首领的技能使用概率暂为 75%，普通攻击占其余机会；技能会先按冷却、生命条件过滤，再按权重选择。

## 掉落与兑换

- 普通副本不再掉落专属武器或徽记，通关提供一份 T1 通用武器碎片。稀有采集机会、稀有种子和高级炼金配方改由普通本通关开启，供深层准备使用。旧普通副本兑换项已从配置移除。深层副本的装备及兑换路线保留。
- 普通副本首通记录用于深层前置；首通不额外发放徽记。掉落预览与实际奖励使用同一份配置。
- 原野外精英专属武器的最终归属、入门本经验效率、普通本波次强度与深层数值仍待数值设计。

数值是首版基线，尚未经过长时间挂机收益与全队配装平衡测试。

## 配置入口

| 文件 / 配置段 | 调整内容 |
| --- | --- |
| `Game.Server/world.json` → `World.Regions` | 地区名称、介绍、等级范围、特色属性、副本和专属武器代码 |
| `Game.Server/world.json` → `World.Dungeons` | 地区归属、挑战类别、经验参考/推荐等级、可见性与大厅首领概要 |
| `Game.Server/appsettings.json` → `DungeonEncounters` | 实际波次、怪物属性与战斗数值、技能组、奖励组、首领标识 |
| `MonsterCombat` | 怪物技能、状态、技能概率与权重 |
| `Rewards.MonsterKills` / `Rewards.DungeonClears` | 金币、经验、补给、武器与通用碎片 |
| `DungeonDepths` | 普通副本到深层副本的显式账号前置映射 |
| `Materials` / `DungeonExchange` | 通用素材与深层兑换 |
| `Weapons` | 武器的元素、技能、基础数值与随机品质规则 |
| `Progression` | 升级经验和角色等级上限 |

调整配置后重启服务端。地区列表由 `GET /api/regions` 返回；副本列表与房间摘要包含稳定的 `RegionCode`。前端仅负责显示和选择，战斗、奖励、库存和兑换继续由后端决定。

启动会校验地区、怪物、技能、奖励和兑换的配置引用，并按副本 `Code` 同步世界配置。现有数据库不会在本轮改动中删除；上线前计划统一删档，届时按新规则生成数据。

## 验证

- `WorldContentTests` 检查六区可见路线、怪物属性、普通本通用素材、完整奖励流程及重复结算幂等性。
- `DungeonDepthFlowTests` 检查账号级普通本前置、逐层解锁、跨账号加入及角色独立精通。
- 数据库初始化测试验证副本目录可重复写入，普通本首通会写入账号通关记录。
- 客户端需验证地区切换、移动端与桌面布局、推荐等级提示、掉落预览及深层前置提示。

当前怪物继续使用已有插画与通用占位图；各区域的独立美术资源可以在后续内容阶段补齐。
