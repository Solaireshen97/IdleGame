# 六个初始地区（Lv.1～10）

地区用于组织大厅挑战与固定属性的特色掉落。玩家可以自由切换地区；没有阵营、出身或旅行消耗限制。各地区均覆盖 1～10 级，同等级路线可交替体验。

## 地区与正式副本

| 地区 | 正式副本 | 首领 | 专属武器属性 | 专属武器 |
| --- | --- | --- | --- | --- |
| 艾尔文森林 | 狗头人矿洞 | 金牙 | 土 | 金牙的精工矿镐 |
| 提瑞斯法林地 | 蜘蛛峡谷 | 织亡蛛后 | 暗 | 织亡者之牙 |
| 杜隆塔尔 | 怒焰裂谷 | 怒焰领主 | 火 | 怒焰裂刃 |
| 丹莫罗 | 寒泉深窟 | 冰牙之王 | 水 | 冰牙寒泉枪 |
| 莫高雷 | 风怒巢穴 | 风怒族母 | 风 | 风怒翎羽弓 |
| 永歌森林 | 晨曦遗迹 | 失控的晨曦守卫 | 光 | 晨曦守望之杖 |

名称与内容是本项目的改编设计。水属性覆盖冰霜主题。

每区有 10 个挑战，共 60 个可见挑战：

- Lv.1～7：每级一个单体讨伐，逐步引入怪物技能与状态。
- Lv.8：正式副本，最低进入等级 8，推荐等级 10；4 波、7 名敌人，最后一名是首领。
- Lv.9～10：两个精英单体讨伐，提供短流程练级与装备积累路线。
- 创建房间、加入房间、上阵替补均由后端检查角色等级；推荐等级不构成硬性门槛。角色升级本身不增加属性，挑战难度仍取决于武器、天赋、技能、补给和队伍。

## 首领的战斗区别

- 金牙：破甲、前排重击与低生命强化。
- 织亡蛛后：前排毒伤、全体毒雾、低生命蛛茧防护。
- 怒焰领主：全体灼烧、破甲劈砍、低生命攻击强化。
- 冰牙之王：前排破甲、全体霜寒降低攻击、低生命冰甲。
- 风怒族母：前排俯冲、全体风暴、低生命战歌强化。
- 晨曦守卫：前排奥术衰弱、全体辉光冲击、低生命护盾。

新首领各有三种技能，沿用服务端持久化的回合意图、技能冷却和战斗前预告。全体危险技能不可打断，可通过防护、净化等方式应对；护盾和强化可驱散。新首领的技能使用概率暂为 75%，普通攻击占其余机会；技能会先按冷却、生命条件过滤，再按权重选择。

## 掉落与兑换

- 各首领的专属武器固定元素、名称、基础攻击/生命与技能组合，暂定 18% 掉率；沿用随机品质技能加成，元素不会随机。
- 每座正式副本都有自己的徽记，存入参战角色独立背包。沿用统一奖励池，在通关或战败时结算已获得的击杀奖励；徽记只在通关时发放。
- 普通通关奖励 1 枚徽记；账号首次通关额外 2 枚，共 3 枚。首通范围沿用当前的账号副本通关记录，同账号换角色不会再触发首通。
- 每个副本兑换所提供六种元素各一把武器，每把 6 枚对应徽记。共 36 把独立模板，各自具有名称、数值和技能配置。不能用其他副本的徽记付款。
- 首领专属武器不进入代币兑换列表，保留刷首领的独特目标；兑换武器仍沿用随机品质规则。
- 大厅显示各区的特色武器和选中挑战的掉落预览；商店的“副本兑换”页按副本筛选。

数值是首版基线，尚未经过长时间挂机收益与全队配装平衡测试。

## 配置入口

| 文件 / 配置段 | 调整内容 |
| --- | --- |
| `Game.Server/world.json` → `World.Regions` | 地区名称、介绍、等级范围、特色属性、副本和专属武器代码 |
| `Game.Server/world.json` → `World.Dungeons` | 地区归属、挑战类别、最低/推荐等级、排序及大厅首领概要 |
| `Game.Server/appsettings.json` → `DungeonEncounters` | 实际波次、怪物属性与战斗数值、技能组、奖励组、首领标识 |
| `MonsterCombat` | 怪物技能、状态、技能概率与权重 |
| `Rewards.MonsterKills` / `Rewards.DungeonClears` | 金币、经验、物品掉率、通关徽记与首通奖励 |
| `Materials` / `DungeonExchange` | 徽记定义、兑换武器与价格 |
| `Weapons` | 武器的元素、技能、基础数值与随机品质规则 |
| `Progression` | 升级经验和角色等级上限 |

调整配置后重启服务端。地区列表由 `GET /api/regions` 返回；副本列表与房间摘要包含稳定的 `RegionCode`。前端仅负责显示和选择，战斗、奖励、库存和兑换继续由后端决定。

启动会先校验地区、怪物、技能、奖励和兑换的配置引用，再迁移数据库并按副本 `Code` 同步世界配置。迁移新增 `Dungeons.RegionCode`；旧副本 ID、房间快照、角色背包与通关记录保留。正在进行的旧房间沿用已保存的怪物配置，新建房间使用更新后的配置。旧测试副本继续隐藏。

## 验证

- `WorldContentTests` 使用实际配置检查六区完整路线、六元素、首领专属掉落、每区六种兑换与独立货币。
- 六个正式副本分别验证创建/加入/上阵的等级限制、完整 7 敌人奖励流程、首通与重复通关、重复结算幂等性、代币隔离及真实兑换。
- 数据库升级测试验证迁移与反复初始化均保留旧房间、怪物生命、通关记录及副本 ID。
- 浏览器验证地区切换、移动端与桌面布局、等级锁定、掉落预览及兑换筛选。

当前怪物继续使用已有插画与通用占位图；各区域的独立美术资源可以在后续内容阶段补齐。
