# 战斗攻击反馈

战场按服务端战报顺序播放出手、命中、伤害、治疗和反击。近战冲刺接斩痕，猎人系发射箭矢，法系发射属性光弹，盗贼系使用交叉斩。每次伤害单独显示，颜色随本次攻击属性变化，优势前缀 `↑`、劣势前缀 `↓`、暴击后缀 `!`（例如 `↑128!`）。数字采用 30–42px 的粗描边斜体，暴击为 36–48px；命中时立即弹出，并同步放射闪光、斩痕、受击与血条扣减。追击、恢复有独立小标签。回合栏累计本回合实际命中次数与战报伤害，击破和最终通关有独立演出。

## 实现边界

- 职业光效：剑士系使用有白色刃线与属性色残光的弧形斩击，盗贼系使用间隔 55ms 的交叉快斩；猎人系使用弓弦蓄光、箭矢及目标穿刺光痕；法师系使用旋转法阵与晶体碎光；祭司系使用圣光弹、十字光柱与星光。治疗和净化在接受者身上升起恢复光点，守护显示盾形光幕。技能光效比普攻稍强，暴击追加刀光；敌人打小队成员时适当缩小特效。所有新增光效使用本地 SVG/CSS，无额外下载，命中时与伤害数字同步出现。追击不重复播放出手或命中特效。

- `Game.Client/Services/BattleFeedbackPlanner.cs` 是现有文本战报的展示适配层。金额、暴击、行动顺序来自服务端日志，不重新计算战斗结果。修改服务端日志格式时须同步适配层及其回归测试。
- 首次进入、重复轮询、跨过多个回合、重开时，不重播历史攻击。击杀回合即使服务端已切到下一只怪物或关闭副本，只要新战报确认旧怪物被击败，仍针对旧目标完整播放。无击杀依据的敌人切换不会重播。完全缺失可识别战报时仅以生命差显示一次无出手者的伤害反馈。
- `Battle.razor` 在演出期间保留开打前的战场快照，操作区继续使用最新服务器状态。先播完所有攻击，再播放怪物消失，最后展示下一只敌人或奖励页；重置、进入新回合和离开页面会取消旧播放。
- 页面预加载角色、怪物与战场背景图片；开播前等待图片下载并解码，期间显示“正在载入战斗画面…”，不提前计时。下载失败或超过 8 秒时清理演出并同步真实结果，避免卡在出手途中。
- 魂印采用魂印自身属性及共享的克制规则。固定中毒、天赋反击等未参与属性计算的伤害不标记克制箭头。战报历史通常保留 80 条，但完整保留单次结算批次，避免长连击被截断。
- 普攻追击附着在同角色紧邻的普攻或二连击上：仅播放一次出手和命中特效，追击伤害数字延后 90ms 独立显示，血量与累计伤害仍逐段更新。真正的二连击及独立技能保留各自的出手；缺失前置攻击的追击不会误并入其他角色或技能。
- 技能名显示在释放者附近，保持释放者原队列位置，避免近战冲刺时跟到战场中间；守护、打断、实际增益与异常状态、净化、驱散、冷却缩短和药剂增伤显示在效果接受者附近。提示避开该单位血条，边缘使用指向单位的标记，长名称换行；重叠的旧提示由新提示替换，不把文字移到其他单位。正负状态取自房间状态详情；未识别的状态显示原名称，不推测增益或异常。提示不计入伤害命中。
- `battle-combat.js` 仅管理独立特效容器、动画和血条属性。即时战况文字使用独立空节点，避免替换 Blazor 管理的文本节点。特效样式位于 `battle-combat.css`。
- 一次攻击间隔 180–460ms，纯效果事件停留 300ms；每个数字保留 2.2 秒。首个数字出在受击目标的身体中心，后续伤害沿同一目标上下错开，避开该目标血条；角色受伤与治疗也使用各自的位置，并避让相邻角色的数字。根据图片实际缩放后的高度定位，避免落在窄角色槽的空白处。位置满时分批显示全部伤害，普攻与追击在出手前同时预留位置，避免追击被已有数字延迟。战场至少保留 160px 高度，较矮窗口可以滚动查看操作区。最后一击收势后怪物用 620ms 消失，数字读完后展示 780ms 击破提示。动画不占用准备、选技能、打开详情等操作。
- 页面切入后台会立即终止演出并回到真实状态。遵从系统“减少动态效果”偏好，停用飞行、位移和粒子，只保留结果、血量及一次回合摘要播报。
