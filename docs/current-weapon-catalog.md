# 当前六属性武器清单

整理日期：2026-09-28。按火 → 水 → 土 → 风 → 光 → 暗排列。技能档位与战斗公式见[当前武器技能三档设计](weapon-tier-balance.md)。

本清单记录六属性区域掉落调整后的当前配置。逐怪主、副掉落见 [区域掉落明细](region-loot-design.md)。

数据来源：`Game.Server/appsettings.json` 中的 Weapons、Rewards、DungeonEncounters、Shop、DungeonExchange，以及 `Game.Server/world.json`。旧版隐藏关卡的兼容引用按 Weapons.Replacements 换算；当前区域怪物直接引用正式武器编号。

## 统计与阅读说明

- 共 132 个武器模板，每个属性 22 个；当前这些模板的物品等级全部为 1。
- 120 个用于当前六区域的战斗、兑换或商店，另有 5 个历史职业初始武器模板、3 个旧版隐藏关卡武器、4 个没有当前获取入口的保留模板。新角色直接装备十把对应属性的商店武器：剑士火、祭司光、法师水、猎人风、盗贼暗；首把锁定，其余可替换。
- 攻击／生命为模板基础值；现有模板的每条已配置技能均从 Lv1 开始。未标注档位的旧单效果技能为中档。六把首怪主武器的第二技能在突破阶级 3 才解锁；表中的 Lv 不含强化等级。
- 普通讨伐按怪物进度为 3% + 1%、6% + 2% 或 10% + 4% + 2%；区域副本小怪为 4% + 1% 或 6% + 2%。精英专属掉率为 3%，区域副本 Boss 专属掉率为 5%，各有一把同属性普通武器 2%。
- 区域副本兑换武器每把 12 枚对应代币，其中 6 把对应区域属性的武器也有该区域终局 Boss 的 2% 击杀来源。终局通关的六把高级武器均为区域属性，独立概率为 6%、4%、3%、2%、2%、1%；18 枚兑换与原兑换来源保持不变。
- 首次普通讨伐胜利会额外给账号发放一次该讨伐武器；该新手奖励和常规概率掉落分开。
- 所有新获得武器均为普通品质（突破阶级 0），包括商店、角色初始、怪物掉落、首次讨伐奖励、副本通关与兑换；后续可消耗同款武器或通用突破石主动升阶。
